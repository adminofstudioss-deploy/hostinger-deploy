# LJ Brows Studio - brand & design reference

## Colour palette (CSS variables in `assets/style.css`)

| Token | Hex | Use |
|---|---|---|
| `--cream` | `#FBF8F2` | page background |
| `--ink` | `#2F3523` | headings, body text |
| `--mute` | `#5d6548` | secondary text |
| `--olive` | `#8C9A5B` | primary buttons, accents |
| `--olive-l` | `#DCE3C3` | soft backgrounds, footer |
| `--olive-d` | `#5A6B33` | active nav, dark panels |
| `--pink` | `#F4D3DA` | secondary buttons, highlights |
| `--pink-d` | `#E3A6B5` | gradients, details |
| `--gold` | `#B8975A` | luxury accents (booking CTA, QR frame, sparkles) |

## Typography

- Headings: **Playfair Display** (serif)
- Body / UI: **Inter**
- Both load from Google Fonts in each page `<head>`.

## Style files

- `assets/style.css` - original design system (glass cards, bento grid, buttons).
- `assets/hifi.css` - hi-fi layer: top bar, Book Now CTA, footer, image slots, online booking panel.
- `assets/main.js` - cart drawer, mobile menu, reveal-on-scroll, parallax, contact form (mailto).
