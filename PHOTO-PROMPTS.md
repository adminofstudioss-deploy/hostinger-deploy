# LJ Brows Studio - photo list + AI prompts

Put the finished photos in **`assets/photos/`** using the exact file names below (all `.jpg`).
The site already looks for these files. If a file is missing, that spot shows the old illustration, so you can
add photos one by one and push to GitHub whenever you like.

Tips for every image
- Palette to match the site: soft cream, olive green, blush pink, a touch of gold. Natural window light, clean and calm.
- Add to every prompt: "photorealistic, professional beauty photography, soft natural light, shallow depth of field, no text, no watermark, no logo".
- Generate larger than needed, then export as JPG (quality 80-85). Keep each file under about 300 KB so the site stays fast
  (https://squoosh.app is a free way to resize/compress).
- Check hands, eyes, and eyebrows closely. AI often gets them wrong. Regenerate until they look natural.
- For people shots, a face or a close crop of eye/brow both work. Close-up crops hide most AI mistakes.

## Honest-use note

AI photos are fine for mood and ambience. Please avoid using them as "our real work / real results" (before-after, named
staff, or the actual studios) since customers may take them as real. For those, use real photos from the studio when available.
